# Лабораторная работа №2 — Основы Java

## Что реализовано
- Целочисленные типы и переполнение
- Вещественная арифметика и epsilon-сравнение
- Побитовые операции
- Работа со строками (палиндром, Цезарь, разворот слов)
- Одномерные и двумерные массивы
- Перегрузка методов, varargs, рекурсия
- Консольное меню (`do-while` + `switch`-expression)
- Ручная сборка в исполняемый JAR

## Как собрать и запустить
```bash
chmod +x build.sh
./build.sh
java -jar lab2.jar
